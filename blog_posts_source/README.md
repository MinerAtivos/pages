# Blog Posts Source

Coloque seus arquivos .html ou .txt aqui para serem processados pelo script `update_blog.py`.

## Formato de Metadados (Cabeçalho)

No topo de cada arquivo, adicione o seguinte bloco de metadados:

```html
<!--
Title: Título da Postagem
Date: YYYY-MM-DD
Tags: Tag1, Tag2, Tag3
Image: assets/blog/imagem-especifica.png (Opcional)
-->
```

O restante do arquivo será o conteúdo da postagem. Se for HTML, ele será preservado. Se for texto simples, será convertido para parágrafos básicos.
